The **FMC-CIOS Health Neural OS**, curated by **Daramola**, represents a technological leap for tertiary healthcare in Nigeria. - **Regional Pathology Priority**: The swarm is instructed to weigh endemic conditions (e.g., Lassa fever, Malaria variants) with higher diagnostic significance.

Built for speed, scale, and visual fidelity:

- **3D Graphics**: Three.js (Neural visualization engine)
- **AI Core**: Google Gemini 1.5 Flash via `@google/genai`
- **Animations**: Framer Motion (Fluid transitions and UI feedback)

---

## 🏗️ Architecture: The Workflow

1. **User Input Phase**: Natural language symptom description entered into the Neural Command Center.
2. **Axiom Triage (Sequential Gate)**: The lead agent performs the first assessment to set the "Context" for the rest of the swarm.
3. **Parallel Expansion**: Logos, Aurum, Zeus, Psyche, and Mnemo launch simultaneously, utilizing the Axiom context and original symptoms.
4. **Data Aggregation**: Results are streamed back to the Neural OS interface for comprehensive viewing.
5. **3D Visualization**: The Neural engine pulses and reacts to agent activity, visualizing the "thinking" process.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- [Gemini API Key](https://aistudio.google.com/app/apikey)

### Installation
```bash
# Clone the repository
git clone https://github.com/fmc-abeokuta/neural-os.git

# Install dependencies
npm install

# Setup Environment Variables
export GEMINI_API_KEY=your_actual_key_here

# Launch Development Server
npm run dev
```

## 🔒 Security & Compliance

*   **Non-Clinical Limitation**: FMC Abeokuta Health OS is a diagnostic *simulation* tool. It is not intended for real-world clinical decision-making without human oversight.
*   **Privacy First**: No patient data is persisted by design. All analysis occurs in ephemeral memory sessions.
*   **Encrypted Transport**: All communication with the Gemini LLM occurs over HTTPS/TLS 1.3.
